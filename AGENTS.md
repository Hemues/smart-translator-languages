Written 2026-10-31 (CET). Reader: an agent (possibly a less capable local model) that must change the pack index or its
files without any session memory. This file holds the rules, the traps and the verified commands. The user manual is

## Documentation discipline

- Documentation is part of the change. When a pack, the index format, a release tag or a licence changes, update README.md,
  this file, and NOTICE.md in the same commit.
- Postmortems go to LESSONS-LEARNED.md. Phase history goes to STORYLINE.md.
- Before you finish, check that the docs say what was actually tested, committed, released or skipped.

## What this repository is

The public pack repository of the Smart Translator app. Three things live here: `packs.json` (the index the app reads on `main`),
`components.json` (the metadata that `make_index.py` turns into the index), and the tooling (`make_index.py`, `add_components.py`,
`fetch_voices.sh`). The pack files themselves are GitHub release assets, never git objects. They are staged in `dist/` on the
host, which is git-ignored.

## File ownership and boundaries

| Path | Owner and rule |
| --- | --- |
| `packs.json` | generated by `make_index.py` only. Never edit by hand. |
| `components.json` | edited by people and by `add_components.py` (which refreshes derived fields only, never hand-edited ones). |
| `make_index.py` | the one writer of `packs.json`. Keep its output format: the app reads `index_version`, `min_app_version`, `components[]` with `id`, `kind`, `bytes`, `sha256`, `urls`. |
| `add_components.py` | describes new files from their names and model cards. Its `GENDER` table is an open owner decision (see Traps). |
| `fetch_voices.sh` | the voice download script. Runs as root on 11.1.0.2. Uploads with `--clobber`. Read Traps before re-running it. |
| `NOTICE.md` | licences and attributions. A licence claim is added in the same commit as its file. |
| `dist/` | the pack files. Git-ignored. Never commit. |
| `README.md` | the user-facing description. Its line endings are CRLF in git (keep them; see Traps). |

## Traps (read before changing anything)

- **An asset under an existing name is a silent break (rule from README, 2026-09-29).** Old app builds keep working from the old
  release tag only if the asset under that tag does not change. Give a changed file a new asset name, or a new tag (`packs-v2`,
  `voices-v2`) and move that component's `release_tag` in `components.json`. `fetch_voices.sh` re-uploads with `--clobber`; use that
  flag only for an asset that no build depends on.
- **The index is live the moment `main` is pushed.** The app reads `packs.json` from `main` at every start. A broken index reaches
  every install at its next start. Run `make_index.py --check` after every change and before the push. Read the diff of `packs.json`
  (only `generated`, the new entries and the changed hashes should differ).
- **Visibility is part of the app's behaviour (2026-10-01).** The repository was made public by hand so that the default index
  answers without a login. Do not make it private. If it is ever private, the app logs
  `pack index: could not fetch … (HTTP 404) — using the built-in list` and uses the built-in list, which has the upstream URLs as second source.
- **The creation script says private (2026-10-31).** `_release-scripts/mk_languages_repo.sh` creates the repository with `--private`.
  That is out of date. Do not run it on an existing repository expecting a visibility change.
- **Voice gender labels (open, 2026-10-31).** 26 voices carry `"gender": "f"` or `"m"`, from a hand-written name table in
  `add_components.py`. The app shows "· female" or "· male". AGENTS.md of the app forbids labelling a voice by its name. Do not add
  entries to `GENDER`. The owner decides whether to remove the labels (LESSONS-LEARNED.md).
- **A licence follows the file.** Parakeet is CC-BY-4.0 (attribution required, see NOTICE.md). Silero is MIT. A Piper voice carries its
  dataset's licence (CC0, CC-BY, CC-BY-SA and others), read from the model card into `packs.json`. Nothing non-commercial is
  distributed. A research paper's or a repository's licence file does not settle a dataset licence: read the model card and the source
  page (standing rule of the fleet).
- **Personal voices never come here.** A voice made from a person's recordings goes to a private index on the LAN or over WireGuard,
  with the person's written consent. Never upload such a file to a release of this repository.
- **Names carry dates.** `sherpa-onnx-omnilingual-asr-1600-languages-300M-ctc-v2-int8-2026-02-05.tar.bz2` is the upstream name. Keep
  upstream names; they make the upstream URL in `components.json` work.
- **A pack removed from the index leaves installed copies unmanaged.** The app wave-11 notes list this as open: an index that drops an
  installed pack leaves the pack installed and unmanaged (smart-translator AGENTS.md). Delete an asset only after no build needs it.
- **The pack size on the phone is not the download size.** Parakeet is 487 MB to download and 671 MB on the phone. Plan the README
  and the storage notes with both numbers.
- **Upstream checksums are the proof of byte identity.** NOTICE.md says the Parakeet and Silero files are byte-identical to the
  sherpa-onnx assets (sha256 given). Keep that claim true: never re-compress a file for upload.

## What never to do

- Never commit `dist/`, a `.tar.bz2`, an `.onnx`, a personal voice, a token or a `gh` config file.
- Never make a pack file a git object (GitHub caps git files at 100 MB; releases allow 2 GB per asset).
- Never change `main` history (no force-push); the app reads it.
- Never run `fetch_voices.sh` from an agent session without the owner's word: it uploads to GitHub as root.
- Never let a script run `git add -A` on this repository without `dist/` excluded (it is excluded by `.gitignore`; check anyway).

## Line endings

`README.md` is CRLF in git HEAD (59 lines at HEAD, 115 lines after the 2026-10-31 documentation pass; all CRLF). The other files
added on 2026-10-31 are LF. After any edit on the share, check `tr -cd '\r' < FILE | wc -c` against the line count. Do not count CRs
with `grep -c $'\r'` in Git Bash: it counts lines containing the letter r.
